**Fishing Buddy**

A [BlishHUD]([url](https://blishhud.com/)) module for Guild Wars 2 that helps you find fish - what day/night cycle you're in, where to find specific fish, tracking achievement progression and showing Daily.

**Features**
> Day/night clock - display current day/night state for both Tyria/Nayos and Cantha/Castora + how much time's left until the next phase

> Today's daily fisher - shows the current Daily Fisher from the EOD achievement pool

> Full fish database - every fish with its rarity, fishing hole, favoured bait, where to find them and at what time of the day. All expansions supported.

**IMPORTANT:** Required fishing power is NOT included atm as I couldn't find the requirements for Janthiri and Castoran fish in the wiki

> Filter options - continent, region, achievement collection, bait and available during the current time of the day

> Hide collected - hides fish you've already caught, using your account's achievement progress (requires an API key with account and progression permissions).

> Search box - search for any fish by its name

**Installation**

Atm only manual installation via GitHub is available (pending Blish approval) - download the bhm file and copy it to the modules folder (by default it should be ~\Documents\Guild Wars 2\addons\blishhud\modules\ 

**API Permissions**

> Account - required to authenticate the API key.

> Progression - required to read your fishing achievement/collection progress, used for the "Hide collected" filter.

> No data is sent anywhere outside the standard GW2 API calls made directly to ANet's servers.
